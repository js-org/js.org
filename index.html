What is WetterNavi?

WetterNavi is a hybrid weather and navigation application built with a Flutter frontend and a Node.js backend. It features Jony, an AI companion powered by the Gemini Live API that communicates via real-time audio, video, and text.

JavaScript / Node.js Architecture

The backend is built entirely with JavaScript (Node.js, ES modules) and includes:

  • WebSocket server (ws) for bidirectional real-time communication between the Flutter app and Gemini Live.
  • Express REST API for weather, restaurants, chat history, and user preferences.
  • PostgreSQL (pg) for persistent memory, presence tracking, and chat history.
  • Telegram bot (grammy) as an autonomous agent that works without the app.
  • Mailjet integration for sending Instagram carousel scripts and generated images via email.
  • Groq / Cloudflare Workers AI for free script and image generation.
