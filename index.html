Features

Small surface, serious engineering

A ground-up overhaul of the original single-file prototype — every layer tightened, validated and streamed.

True token streaming

/api/chat pipes upstream SSE deltas straight to the browser — no fake cursor, no dump-at-the-end. Stop keeps the partial reply and saves it.

Agent mode

Flip a toggle and Pseudo can call web_fetch, wikipedia_search, calculator and now before it answers — with live tool chips in the UI.

Three model modes

Flax (fast), Scythe (creative) and Nova (GLM) behind one preset picker — availability is probed per deployment, with automatic fallback.

Full Markdown

GFM tables, lists and links, plus syntax-highlighted code blocks with copy buttons — rendered safely, links forced rel="noopener".

Local-first, private

History lives in localStorage only — migrate from the old version automatically, export a backup from Settings, delete anytime.

Security by default

Persona locked server-side, Zod-validated input, per-IP rate limiting, SSRF-guarded fetching, and API keys that never reach the browser.

Agent mode

It doesn’t just answer — it looks things up

Toggle agent in the composer and the server runs a model-agnostic tool loop, then streams the final answer token-by-token.

  1. The model gets tool specs

    Each step calls the model with the tool definitions; any tool_calls come back for execution.

  2. Tools run server-side

    Every tool is time-boxed (10–14 s) and its output capped (~3.5 KB). web_fetch blocks private and internal hosts.

  3. Results loop back

    Outputs are fed to the model again, repeating until a final answer — or the budget runs out.

  4. The answer streams

    Tool calls appear as chips above the reply, persisted with the message; the final text streams live into the chat.

Self-host

Your keys, your deployment

A standard Next.js app — clone, set one or two env vars, deploy. Keys are read server-side only.

  • 1Clone and install — bun install, npm or pnpm all work.
  • 2Add provider keys — Groq’s free tier alone unlocks Flax; Scythe needs one Z.AI key.
  • 3Deploy — push to Vercel, or run bun run dev locally at localhost:3000.
.env.local
# pick either (or both) — availability is auto-detected
GROQ_API_KEY=gsk_your_groq_key
ZAI_API_KEY=your_zai_key

# optional — adds the web_search tool in agent mode
TAVILY_API_KEY=tvly_your_tavily_key
